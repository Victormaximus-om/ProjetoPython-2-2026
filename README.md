## Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo de analisar dados de vendas utilizando a biblioteca Pandas e apresentar informações por meio de gráficos.

## Funcionalidades

- Exibição de estatísticas gerais das vendas.
- Análise de faturamento por categoria.
- Gráfico de vendas ao longo do tempo.
- Gráfico de faturamento por categoria.
- Histograma da distribuição das vendas.
- Listagem dos 10 produtos com maior faturamento.
- Listagem dos 10 produtos mais lucrativos.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn

## Como executar

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Execute o programa:

```bash
python main.py
```
